# Issue tracker: GitHub

Issues and specifications for this repository live in GitHub Issues at
`vuquangkhtn/problems-solving`. Use the `gh` CLI for issue operations.

## Conventions

- Create issues with `gh issue create`.
- Read issues with `gh issue view`.
- List issues with `gh issue list`.
- Comment with `gh issue comment`.
- Apply or remove labels with `gh issue edit`.
- Comment with the resolution before closing an issue.
- Infer the repository from the configured Git remote.
- Before the first issue write in a session, verify the target with
  `gh repo view --json nameWithOwner`.
- File issues only in this repository.
- Pull requests are not a triage request surface.

When a skill says “publish to the issue tracker,” create a GitHub issue.
When a skill says “fetch the relevant ticket,” read the corresponding
GitHub issue.
